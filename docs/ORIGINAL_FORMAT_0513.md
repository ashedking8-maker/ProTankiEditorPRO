# Additional native map fields observed in the supplied ProTLVK archive

Archive `protlvk-bin-main(1).zip` is game tester data, not the source of the original map editor. Read-only ElementTree scan of 201 map XML files (no parse errors) saw root sections: `collision-geometry`, `static-geometry`, `lights`, `spawn-points`, `bonus-regions`, `special-geometry`, `way-points`, `ctf-flags`, `dom-keypoints`, plus rare `asl-point` and `asl-flags` in `map_event_furyroad.xml` and `map_ny_yorkshire.xml`. Entries include 4,246 bonus regions, 10,434 spawn points, 4,679 special boxes, 548 DOM points and 400 omni lights. Known bonus-type occurrences: nitro 893, crystal_100 744, damageup 743, crystal 723, armorup 672, medkit 461, crystal_500 6, empty 4. Recorded modes include dm 3719, tdm 3706, ctf 3700, dom 3649 and as 194. Empty bonus types and modes are not silently rewritten. All special actions seen were kill or kick; all light types seen were omni.

We now allow explicit creation with crystal_500 and mode as, while retaining the exact string rather than inventing its gameplay meaning. The AS filter is not independently implemented; All shows otherwise unclassified native mode regions. Root ASL point/flag elements and waypoint fields remain opaque, copied through on save. This is a discrepancy report, not a claim of feature parity with an unavailable original editor.
