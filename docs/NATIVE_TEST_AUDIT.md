# Retired native tester

The in-editor tank preview, physics simulation and tank renderer were removed in 0.5.6. The Test button now launches the separately installed original `ProTLVK32.exe`, after a first-use Windows file picker, and remembers only the EXE path. No map, configuration or game files are modified by Test.

The editor remains a legacy XML map editor; map compatibility needs real testing in the original program.
